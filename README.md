# HIVE

Plataforma B2B de inteligencia operativa de inventarios para grandes bodegas industriales: conciliación basada en
evidencia, gemelo digital 3D, analítica explicable y recomendaciones con aprobación humana.

Este repositorio contiene, por ahora, un **prototipo demostrativo con datos sintéticos** (demo de 90 s, 19-11-2026).
No es el MVP industrial.

- Cómo ejecutar la demo en Windows 11: [`README_DEMO.md`](README_DEMO.md)
- Guion de 90 segundos: [`DEMO_SCRIPT_90S.md`](DEMO_SCRIPT_90S.md)
- Implementado / parcial / pendiente: [`STATUS_DEMO.md`](STATUS_DEMO.md)
- Especificaciones de producto: [`docs/`](docs/)

```powershell
cd frontend
npm install
npm run demo   # http://127.0.0.1:4173/
```
